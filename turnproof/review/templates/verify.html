Verify a packet

Anyone can check a TurnProof packet: the airline, an auditor, a judge. Drop the packet JSON; add the frames zip and the event log to check the frame hashes and the chain too. The page runs the same verify_packet.py you can download from the repository and run yourself — no account, no API key, no trust in us.

Files

Checks: schema version · required fields · no machine speculation field · SHA-256 of each redacted frame · event-log hash chain and the packet's anchor in it · packet hash over canonical JSON · Ed25519 signature.
